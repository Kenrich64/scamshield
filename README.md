# ScamShield — Explainable, Obfuscation-Robust SMS Scam Detection for India

[![Live Demo](https://img.shields.io/badge/Live_Demo-Vercel-black?style=flat&logo=vercel)](https://scamshield-liard.vercel.app)

Detects Indian-context SMS scams (KYC, UPI refund, electricity disconnection, Hinglish messages), explains *why* a message looks like a scam, and stays robust to filter-evasion tricks such as leetspeak, homoglyphs, zero-width characters and URL obfuscation.

**Live Web App**: [https://scamshield-liard.vercel.app](https://scamshield-liard.vercel.app)

The project lives in [`scamshield/`](scamshield/). See [scamshield/README.md](scamshield/README.md) for the pipeline, experiments, how to run it and its limitations.
